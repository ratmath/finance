@ratmath/finance

Money that adds up to the cent

The mathematics of finance with exact money: time value, loans with schedules that reconcile to the cent, bonds and yield curves, and the commonly needed building blocks for simulating a financial situation over time. A full simulation environment would be an app on top.

Planned, not built yet. This site is the frame the package will grow into. The full plan is in the library roadmap, and the RatMath Shelf page lists what exists across all the libraries.

What it will cover

  • Money with explicit rounding rules, day counts, the time value of money, annuities.
  • Loans and amortisation schedules, cash flows, rates of return.
  • Bonds, interest rates and yield curves.
  • Scenarios: exact projection of a set of accounts and flows, comparison and sensitivity.
  • Uncertain inputs and repeated runs, with seeded randomness.
  • Portfolios, options and life contingencies.

How the docs will be laid out

Like every library on the Shelf: this overview, an Explore page for trying things without writing code, a Reference listing every function, and one page per topic that explains the usage and the mathematics. Every page ends with a box of code you can edit and run.
