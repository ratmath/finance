Reference

Everything in the library

Every export of @ratmath/finance, with what it takes and what it returns. Amounts and rates go in as whole numbers, Core Rationals or strings ("1234.56", "7/8", "4.5%"); a JavaScript number that is not whole is refused. Results are Rationals when exact and RationalIntervals, proven to contain the value, when a root or an exponential is involved; functions that return intervals take digits.

Money, rounding, dates

ExportWhat it does
amount(x), rate(x)Read an exact amount or rate.
round(x, { places = 2, mode = "half-even" })Round by a named rule: half-even, half-up, half-down, up, down, floor, ceil. See Money and rounding.
format(x, { places, mode, currency, separator, percent })An amount as text, rounded for display.
show(x, places)A Rational or an interval as a decimal; an interval prints as one number when its rounding is certain.
allocate(total, weights, { places })Shares that add up to the total exactly.
power(base, exponent, digits), exp(x, digits), ln(x, digits)Exact when possible, otherwise enclosed.
date(x), CalendarDateA calendar date: addDays, addMonths, compareTo, equals. See Dates and day counts.
daysBetween(a, b), dayCount(from, to, convention), DAY_COUNTS, isLeap(y)Days, and { days, yearFraction } under a convention.
FinanceErrorWhat the library throws, with a code: inexact, bad-number, bad-rounding, bad-date, no-solution, negative-amortisation, never-repaid, bad-flows, bad-bond, bad-curve, bad-scenario and others.
